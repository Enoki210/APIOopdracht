Pokemon Zoeker

Een website waarmee je informatie over verschillende Pokémon kunnen opzoeken. Dit project is gebouwd met HTML, CSS en JavaScript
 Gebruikte API
Dit project maakt gebruik van de PokéAPI (https://pokeapi.co/)

Hoe werkt de website
Pokémon Zoeken: Zoek op naam om direct de stats van een specifieke Pokémon te zien.
Shiny knop: Met de Shiny knop kun je wisselen tussen de standaard Pokémon en de Shiny versie van de Pokémon.
search lijst: Een horizontale balk met alle Pokémon waarmee je snel een pokemon kan zoeken als je de naam er niet van kent.

Hoe kun je dit project lokaal openen
Volg deze eenvoudige stappen om de applicatie lokaal op je computer te draaien:
Clone de repository of download de bestanden als ZIP en pak ze uit
